# Problem F. 背包

（2025ICPC 国际大学生程序设计竞赛全国邀请赛（武汉））

## 题目描述

有 *n* 组物品，每组物品有 *a~i~* 个，每个物品的重量为 $2^{b_i}$。有 *m* 个背包，每个背包的承重为 *k*。目标是将所有物品放入背包中，使得每个背包的总重量不超过 *k*，且最小化 *k*。

请注意：

- 每个物品必须放入恰好一个背包
- 来自同一组的物品可以放入不同背包
- 来自不同组的物品可以放入同一个背包

## 输入格式

第一行输入一个整数 *T*（1≤*T*≤10^4^）表示测试数据组数。对于每组测试数据：

- 第一行：两个整数 *n* 和 *m*（1≤*n*≤2×10^5^，1≤*m*≤10^9^）
- 接下来 *n* 行：每行两个整数 a~i~ 和 b~i~（1≤*a~i~*≤10^9^，0≤*b~i~*≤109）

保证所有测试数据中 *n* 的总和不超过 2×10^5^。

## 输出格式

每组数据输出一行一个整数，表示最小的 *k* 对 998244353 取模后的结果。

## 示例

| 标准输入                                                     | 标准输出          |
| :----------------------------------------------------------- | :---------------- |
| 2 <br />5 4<br />3 0<br />2 3<br />3 1<br />1 3<br />2 1<br />2 20250427<br />000000000 1000000000<br />114514 1919810 | 10<br />628956724 |

## 样例解释

第一组数据：

- 5组物品，4个背包
- 物品：3个(2⁰), 2个(2³), 3个(2¹), 1个(2³), 2个(2¹)
- 最小承重k=10

第二组数据：

- 2组物品，20250427个背包
- 物品：10⁹个($2^{10⁹}$), 114514个($2^{1919810}$)
- 最小承重k=628956724 (取模后)
