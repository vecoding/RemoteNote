# D. 线段覆盖问题

## 题目描述

有一条被划分为 $m$ 个单元格的线性带，单元格从左到右编号为 $1$ 到 $m$。

给定 $n$ 条线段。每条线段由四个数字定义：$l$、$r$、$p$ 和 $q$ —— 该线段覆盖从 $l$ 到 $r$（包含端点）的单元格，且存在的概率为 $\frac{p}{q}$（各线段独立存在）。

你的任务是计算每个单元格**恰好**被一条线段覆盖的概率。

**输入格式**

第一行包含两个整数 $n$ 和 $m$（$1 \le n, m \le 2 \cdot 10^5$）。

接下来 $n$ 行，每行包含四个整数 $l_i$、$r_i$、$p_i$ 和 $q_i$（$1 \le l_i \le r_i \le m$；$1 \le p_i \lt q_i \lt 998244353$）。

**输出格式**

输出一个整数 —— 每个单元格恰好被一条线段覆盖的概率，结果对 $998244353$ 取模。

形式上，该概率可以表示为不可约分数 $\frac{x}{y}$。你需要输出 $x \cdot y^{-1} \bmod 998244353$ 的值，其中 $y^{-1}$ 是满足 $y \cdot y^{-1} \bmod 998244353 = 1$ 的整数。

**Input**
3 3
1 2 1 3
3 3 1 2
1 3 2 3
**Output**
610038216

**Input**
2 3
1 2 1 2
2 3 1 2
**Output**
0

**Input**
8 5
1 3 1 2
1 5 1 6
1 4 4 5
5 5 1 7
4 5 1 2
4 5 2 5
3 3 2 7
1 2 1 3
**Output**
94391813

### 题意

给定n个片段区间$[l_i,r_i]$,该片段覆盖该区间的概率为p/q，求1~m所有节点均只被覆盖一次的概率。

## 思路

考虑dp[i]为1\~i内所有节点均只被覆盖一次,i+1\~m内所有节点均不被覆盖的概率，显然dp[j]与dp[i]与一条区间为[i,j]的片段有关。
思考可以发现$dp[j]+=dp[i]/(q-p)*p;$即dp[j]其实为dp[i]将当前[i,j]线段不选改为选的概率，累加是由于可能存在多条线段由不选变为选会是的1\~j均被覆盖一次，j+1\~m不被覆盖。

## 代码

```C++
#include <bits/stdc++.h>
#define ll long long
using namespace std;
const ll MAXN = 2e5 + 10;
const ll mod = 998244353;
struct node
{
    ll l, p, q;
    node() {};
    node(ll x, ll y, ll z) : l(x), p(y), q(z) {};
};
ll n, m, f[MAXN];
vector<node> a[MAXN];
ll inv(ll x)
{
    ll ret = 1, k = mod - 2;
    while (k)
    {
        if (k & 1)
            ret = (ret * x) % mod;
        x = (x * x) % mod;
        k >>= 1;
    }
    return ret;
}//快速幂求逆元
int main()
{
    cin >> n >> m;
    f[0] = 1;
    for (ll i = 1, l, r, p, q; i <= n; i++)
    {
        cin >> l >> r >> p >> q;
        a[r].push_back(node(l, p, q));
        f[0] = (f[0] * (((q - p) * inv(q)) % mod)) % mod;//预处理全都不选的情况
    }
    for (ll i = 1; i <= m; i++)
        for (auto [l, p, q] : a[i])
            f[i] = (f[i] + ((((f[l - 1] * inv(q - p)) % mod) * p) % mod)) % mod;//转移状态
    cout << f[m];
    return 0;
}
```
