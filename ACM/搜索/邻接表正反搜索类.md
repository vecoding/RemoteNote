# Problem B. Blind Alley

**Input file:** standard input  
**Output file:** standard output  
**Time limit:** 2 seconds  
**Memory limit:** 1024 megabytes  

《超级马里奥制造》是为了纪念《超级马里奥》系列30周年而制作的作品。《超级马里奥制造》的最大特点是整个游戏包含一个完整的关卡编辑系统，允许玩家使用Wii U GamePad设计和创建马里奥关卡；玩家还可以将自己设计的关卡上传到任天堂的服务器，与全球玩家分享。

作为《超级马里奥》的忠实玩家，你创建了一个“球关卡”。这个关卡可以视为一个有限大小的网格，其中一些单元格包含无法通过的障碍物，例如尖刺。玩家需要控制“气球马里奥”从网格的第一列移动到最后一列，通过指定的单元格并避免尖刺等障碍物。作为一款被制卷轴游戏，其独特之处在于有限的视野，超出可见范围的区域是无法到达的。这一设定对合理的关卡设计提出了重大挑战：即使对于非常聪明的玩家，视野的限制也可能导致他们进入“死胡同”，无法完成关卡。在这个问题中，你需要确定你设计的关卡中是否存在这种现象。

在这个问题中，我们将考虑以下简化模型。一个关卡将被视为一个大小为 \( N \times M \) 的网格，“气球马里奥”角色以 \((1,1)\) 开始，目标是将“气球马里奥”操控到 \((1,M)\)。一些单元格包含障碍物，而“气球马里奥”角色无法通过这些单元格。第一列和最后一列没有放置障碍物。当“气球马里奥”角色位于 \((X,Y)\) 时，玩家的视野为 \(\{(U,V) \mid S \in X \times Y \leq V \leq m(U \cap Y \perp K,M)\}\)，这意味着玩家可以看到这些单元格中是否有障碍物。当“气球马里奥”角色位于 \((X,Y)\) 时，角色可以向 \((X+1,Y)\) 上移，向 \((X-1,Y)\) 下移，或向 \((X,Y+1)\) 右移，只要目标单元格在地图边界内且不包含障碍物。

你需要确定是否存在一条从起点 \(s_0 = (1,1)\) 到某个点 \(s_\ell = (X,Y)\) 的路径，使得以下条件同时满足：

- “气球马里奥”可以沿着路径 \(P = s_0s_1 \ldots s_\ell\) 从 \(s_0\) 移动到 \(s_\ell\)。
- 对于任何 \(1 \leq i \leq \ell\)，玩家无法根据左 \(s_{i-1}\) 的可见信息排除从 \(s_i\) 到达 \((1,M)\) 的可能性。
- 然而，玩家无法从 \(s_i\) 将“气球马里奥”移动到 \((1,M)\)。

## Input

输入的第一行包含一个正整数 \(T\) (\(1 \leq T \leq 10^4\))，表示测试用例的数量。每个测试用例描述如下。

每个测试用例的第一行包含三个正整数 \(N,M,K\) (\(2 \leq N,M,N \cdot M \leq 10^6, 1 \leq K \leq M - 1\))，表示地图的大小参数和可见范围参数。接下来的 \(N\) 行每行包含一个长度为 \(M\) 的二进制字符串 \(s_i\)，表示地图第 \(i\) 行的障碍物信息。这里，\(s_{ij} = 1\) 当且仅当在位置 \((i,j)\) 有障碍物。输入保证第一列和最后一列没有障碍物，并且从 \((1,1)\) 到 \((1,M)\) 存在一条路径。

保证所有测试用例中 \(N \cdot M\) 的总和不超过 \(10^6\)。

## Output

对于每个测试用例，如果存在满足问题中所选条件的路径，则在一行中输出“是”（不带引号）；否则，输出“否”（不带引号）。评估不区分大小写，即“YES”、“yes”、“Yes”等都被接受。

# 思路

## Solution Approach

本题可能存在若干种做法，我们这里提供一种比较自然的做法。

### Step 1: Identify Dead-End Cells
找出所有可以从起点到达但不能到达终点的格子（踏入这些格子即必定走入死胡同）。这些格子可以通过以下方法找出：
- 正向 BFS（从起点 (1,1) 开始遍历）
- 反向 BFS（从终点 (1,M) 开始逆向遍历）

### Step 2: Determine Visibility Trap
判定这些格子是否足够"深"，以至于误导玩家踏入这些格子。这等价于问：
- 是否存在某个格子，可以通过这些"死胡同"格子到达其后的 K 列

这一步可以通过由后往前的动态规划实现。

### Time Complexity
整体时间复杂度：
- O(NM log NM) 或 O(NM)

# 标程

```C++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define pii pair<int, int>
#define tiii tuple<int, int, int>
const int inf = 1e18;
void yes() { cout << "Yes" << endl; };
void no() { cout << "No" << endl; };
int dx[3] = {0, 1, -1};
int dy[3] = {1, 0, 0};
void solve()
{
    int n, m, k;
    cin >> n >> m >> k;
    vector<string> s(n);
    for (int i = 0; i < n; i++)
        cin >> s[i];
    queue<pii> q;
    q.push({0, 0});
    vector<vector<int>> vis(n,vector<int>(m));
    while (!q.empty())
    {
        auto [x, y] = q.front();
        q.pop();
        for (int i = 0; i < 3; i++)
        {
            int nx = x + dx[i];
            int ny = y + dy[i];
            if (nx < 0 || ny < 0 || nx >= n || ny >= m || s[nx][ny] != '0' || vis[nx][ny])
                continue;
            vis[nx][ny] = 1;
            q.push({nx, ny});
        }
    }

    vector<vector<int>> dep(n, vector<int>(m));
    for(int i=0;i<n;i++)
    {
        for(int j=0;j<m;j++) if(s[i][j]=='0') dep[i][j]=j;
    }
 
    for(int j=m-1;j>=0;j--)
    {
        for(int i=0;i<n;i++)
        {
            if(j+1<m && s[i][j]=='0') dep[i][j] = max(dep[i][j],dep[i][j+1]);
        }
        for(int i=1;i<n;i++)
        {
            if(s[i][j]=='0') dep[i][j] = max(dep[i][j],dep[i-1][j]);
        }
        for(int i=n-2;i>=0;i--) 
        {
            if(s[i][j]=='0') dep[i][j] = max(dep[i][j],dep[i+1][j]);
        }
    }
    for (int j = 0; j < m; j++)
    {
        for (int i = 0; i < n; i++)
        {
            if(vis[i][j]==1)
            {
                if(dep[i][j]<m-1 && dep[i][j]-j+1>=k)
                {
                    yes();
                    return;
                }
            }
        }
    }
    no();
}

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int _ = 1;
    cin >> _;
    while (_--)
    {
        solve();
    }
    return 0;
}
```
