# 广东2023ACM省赛B题

## 题目大概

共T组样例。

第1行，给出n，表示有n个格子。$1 \leq n \leq 2^5$

第2行，对于第i个格子，给出a[i]表示在该点种树代价。$1 \leq a_i \leq 1^9$

第3行，给出m，表示一共需要满足m个区间，对于每个区间内必须种一棵树。

第4~4+m-1行，分别给出l和r，表示区间[l,r]。$1\leq l,r \leq n$

### 输入：

 2
 5
 3 2 4 1 100
 3
 1 3
 2 4
 5 5
 5
 7 3 4 2 2
 3
 1 4
 2 3
 4 5

### 输出：

 102
 5



## 思路：

显然，为了满足每个区间至少要有一棵树，对于两个种树的地方i与j（i和j之间没有种第3颗树），i~j之间不能存在一个完整需要种树的区间。

所以我们可以发现，i的取值范围是在j以前最近的一个完整区间的左端l到j-1。

设定dp状态f[k]表示选择在k点种树。

f[j]=min(f[las],f[las+1],...,f[j-1])+a[j]

las为最近完整区间的左端。

对于las可以用各种方法取得。（最优为双指针O(n) )

对于min部分，可以单调队列优化。

## 代码：

```c++
#define ll long long
#include<bits/stdc++.h>
using namespace std;
ll t;
int main()
{
   ios::sync_with_stdio(0);
   cin.tie(0);
   cout.tie(0);
   cin>>t;
   while (t--)
   {
      ll n,m;
      cin>>n;
      vector<ll> a(n+3),lim(n+3),f(n+3),num(n+3);
      vector<vector<ll> > b(n+3);
      for (ll i=1;i<=n;i++)
      {
         cin>>a[i];
      }
      n++;
      cin>>m;
      for (ll i=1,l,r;i<=m;i++)
      {
         cin>>l>>r;
         b[l].push_back(r);
         b[r].push_back(-l);
      }//由于数值很小，可以进行类似桶的操作，方便记录当前位置之前有多少个完整区间
      ll now=0;
      for (ll i=1,j=1;j<=n;j++)
      {
         for (ll it:b[j-1]) 
            if (it<0&&-it>=i) now++;
         while (now>0&&i<j)
         {
            for (ll it:b[i]) 
               if (it>0&&it<j) now--;
            i++;
         }
         lim[j]=i-1;
      }
       //获取对于在j处种树，上一棵树的位置i所能到达的区域i~j
       
       //同样地，可以通过存储l，r位置，并按着r的大小从小到大排序，通过二分获得lim（此处省略）
      ll head=1,tail=1;
      num[tail]=0;
      for (ll i=1;i<=n;i++)
      {
         while (head<=tail&&num[head]<lim[i]) head++;
         f[i]=f[num[head]]+a[i];
         while (f[num[tail]]>=f[i]&&head<=tail) tail--;
         num[++tail]=i;
      }//题目性质发现，对于每个我们查询的区间都是有一定相关性的，可以单调队列维护区间最小，使复杂度优化为O(n)
      cout<<f[n]<<'\n';
       //输入a[i]时进行了n++的特殊处理，引入了a[n+1]=0,对于f[n+1]时选择了a[n+1]不影响最终结果，但可以方便结算答案
       //当然也可以记录最后一个区间的范围，手动求一遍区间f[i]的最小值
   }
   return 0;
}
```
