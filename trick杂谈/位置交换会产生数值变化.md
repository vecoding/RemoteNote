## 序列

给出两个长度为n的序列a[i],b[i]，可以进行若干次操作，每次操作选择一个(1<i<n-1)，使a[i]变成 α[i]-k，a[i+1]变成 a[i+1]+k人并且交换两个数的位置，求从序列a[i]变成序列b[i] 的最小操作数，如果不行输出 -1。

### Input

第一行两个由空格隔开的整数n,k。
第二行几个由空格隔开的整数a1,a2….an。
第三行n个由空格隔开的整数b,b2...bn
保证 $1≤n≤ 10^5,0 ≤ k,ai,bi < 10^9.$

### Output

个数表示最小操作数。
Example

### standard input

3 1
7 4 6
5 7 5

5 2
9 11 8 6 5
13 11 5 6 4

### standard output

2

4

## trick：

$
关键观察\\
每次操作选择位置 i，会交换 a_i和 a_i+1 的位置，同时修改它们的值为:\\
新a_i =原a_{i+1}+k\\
新 a_{i+1} =原a_i-k\\
引入变换 c_i = a_i + k·(i+ 1)，发现操作后:\\
c_i=原a_i +k·(i+1)\\
c_{i+1}=原a_i+1+k·(i+ 2)\\
新c_i= (原a_i+1+k)+k·(i+ 1)= 原a_i+1+k·(i+ 2).\\
新 c_{i+1} =(原a_{i+1} - k)+k·(i+ 2)= 原a_i +k·(i+1).\\
这等价于交换了 c 和 c+1 的值，但数值本身未变!\\
因此，操作等价于交换变换后数组的相邻元素。$

**由此，问题转换为a数组通过k次交换，使其变为b数组（a与b仅数字排列不同），求k。**

## 思路：

使用trick后，只需要离散化求交换次数即可。

## 代码：

```c++
#include <iostream>
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;
const int MAXN=1e6;
int n,k,tree[MAXN];
int lowbit(int x)
{
   return x&(-x);
}
void add(int x)
{
   for (;x<=n;x+=lowbit(x)) tree[x]++;
}
int query(int x)
{
   int ans=0;
   for (;x;x-=lowbit(x)) ans+=tree[x];
   return ans;
}
int minSwaps(vector<int> &a, vector<int> &b)
{
   // 构建元素到位置的映射
   unordered_map<int, vector<int>> posMap;
   for (int i = 1; i <= n; i++)
   {
      posMap[b[i]].push_back(i);
   }

   // 构建置换数组
   vector<int> p(n);
   unordered_map<int, int> ptr; // 记录每个元素的当前位置指针
   for (int i = 1; i <= n; i++)
   {
      int elem = a[i];
      p[i] = posMap[elem][ptr[elem]++]; // 分配b中对应的位置
   }

   int ans=0;
   for (int i = n; i >= 1; i--)
   {
      add(p[i]);
      ans+=query(p[i]-1);
   }//树状数组求逆序对
   return ans;
}

int main()
{
   // 测试用例
   cin >> n >> k;
   vector<int> a(n + 2);
   vector<int> b(n + 2);
   for (int i = 1; i <= n; i++)
   {
      cin >> a[i];
      a[i] += k * i;
   }
   for (int i = 1; i <= n; i++)
   {
      cin >> b[i];
      b[i] += k * i;
   }
   cout <<minSwaps(a, b) << endl;
   return 0;
}
```
