## 题目：
对于一个1\~n的排列a~i~，使其变为另一个1\~n的排列b~i~的最小交换次数。
交换可以选择任意位置。1<=n<=10^8^

## 分析模型：

将问题简化为

对于一个1\~n的排列a~i~，使其变为1，2，3，....，n最小交换次数。

对于该问题，显然可以发现，对于a~i~中不在自己位置上的数字，可以构成k个交换环，对于每个环上的数回到正确的位置上需要环中数个数-1步。

故原问题只需要将b~i~离散化为1，2，3，....，n的序列，a~i~对应一下转换为下面的问题即可。

## 代码：

```c++
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;
int n;
int minSwaps(vector<int> &a, vector<int> &b)
{
   // 构建元素到位置的映射
   unordered_map<int, vector<int>> posMap;
   for (int i = 1; i <= n; i++)
   {
      posMap[b[i]].push_back(i);
   }

   // 构建置换数组
   vector<int> p(n);
   unordered_map<int, int> ptr; // 记录每个元素的当前位置指针
   for (int i = 1; i <= n; i++)
   {
      int elem = a[i];
      p[i] = posMap[elem][ptr[elem]++]; // 分配b中对应的位置
   }

   // 分解循环
   int cycles = 0;
   vector<bool> visited(n+2, false);
   for (int i = 1; i <= n; i++)
   {
      if (!visited[i])
      {
         cycles++;
         int cur = i;
         while (!visited[cur])
         {
            visited[cur] = true;
            cur = p[cur];
         }
      }
   }

   return n - cycles;
}

int main()
{
   // 测试用例
   cin >> n;
   vector<int> a(n + 2);
   vector<int> b(n + 2);
   for (int i = 1; i <= n; i++)
   {
      cin >> a[i];
   }
   for (int i = 1; i <= n; i++)
   {
      cin >> b[i];
   }
   cout <<minSwaps(a, b) << endl;
   return 0;
}
```
