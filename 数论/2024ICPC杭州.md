## Problem M. Make It Divisible

给定一个包含正整数的序列 \(a_{1}, a_{2}, \cdots, a_{n}\)，长度为 \(n\)。我们称区间 \([l, r]\)（\(1 \leq l \leq r \leq n\)）是一个**可除区间**，如果存在一个整数 \(d\) 满足 \(l \leq d \leq r\)，并且对于所有 \(l \leq i \leq r\)，\(a_{i}\) 都能被 \(a_{d}\) 整除。如果整个序列中对于所有 \(1 \leq l \leq r \leq n\)，区间 \([l, r]\) 都是可除区间，那么我们称整个序列是一个**可除序列**。

给定另一个长度为 \(n\) 的序列 \(b_{1}, b_{2}, \cdots, b_{n}\) 和一个整数 \(k\)，找出所有满足 \(1 \leq x \leq k\) 的整数 \(x\)，使得序列 \(b_{1} + x, b_{2} + x, \cdots, b_{n} + x\) 是一个可除序列。由于这样的整数数量可能很大，你只需要输出这些整数的个数以及它们的和。

### 输入

输入包含多个测试用例。第一行包含一个整数 \(T\)（\(1 \leq T \leq 500\)），表示测试用例的数量。对于每个测试用例：

第一行包含两个整数 \(n\) 和 \(k\)（\(1 \leq n \leq 5 \times 10^{4}\)，\(1 \leq k \leq 10^{9}\)）。

第二行包含 \(n\) 个整数 \(b_{1}, b_{2}, \cdots, b_{n}\)（\(1 \leq b_{i} \leq 10^{9}\)）。

保证所有测试用例的 \(n\) 的总和不超过 \(5 \times 10^{4}\)。

### 输出

对于每个测试用例，输出一行，包含两个由空格分隔的整数，第一个整数是满足条件的 \(x\) 的个数，第二个整数是所有满足条件的 \(x\) 的和。

### 示例

标准输入

```
3
5 10
7 79 1 7 1
2 1000000000
1 2
1 100
1000000000

```

  标准输出

```
3 8
0 0
100 5050

```



### 注意

对于第一个样例测试用例，\(x=1\)，\(x=2\) 和 \(x=5\) 是有效的。

对于第三个样例测试用例，所有 \(1 \leq x \leq 100\) 都是有效的。

# 思路：

考虑在已知道+x的值时，对于新数组如何check。发现对于一个数，受他影响的范围为它左边第一个比他小的数，和右边第一个比他小的数，影响范围存在区间性质。假设大的数为a，小的数为b，发现如果a在他的势力范围内是可以整除的，那么b只要可以整除a，那么b也可以整除a的势力范围内的数。这样可以得到区间性质在相邻大数和小数之间的传递性，考虑笛卡尔树（本质单调栈构建）维护。（当然也有魔改版单调栈），可以实现$O(n)$check。

对于gcd问题涉及到+x，首先考虑差分。差分求全数组的gcd后可以发现为了满足要求，$min(a_i+x)$必须是gcd的因子。通过这个方向暴力枚举因子，然后与$min(a_i)$做差，即可算出可能可行的x，相比直接枚举x后相加重新check（时间复杂度$O(kn)$，该方法变成了$O(n\sqrt{n})$，刚好可以通过。

# 代码：

```C++
#include <bits/stdc++.h>
using namespace std;
#define int long long
const int mod = 998244353;
void solve()
{
    int n, k, mi = 2e9, g = 0, cnt = 0, ans = 0;
    cin >> n >> k;
    vector<int> a(n + 3), b(n + 3), s(n + 3), d;
    auto check = [&](int x) -> bool
    {
        int len = 0;
        for (int i = 1; i <= n; i++)
            b[i] = a[i] + x;
        for (int i = 1; i <= n; i++)
        {
            while (len > 0 && b[i] < b[s[len]])
            {
                if (b[s[len]] % b[i] != 0)
                    return false;//神奇判断，由于弹出的数是比他大的，后续维护的栈虽然具有整除性质，但对于当前弹出的数和当前插入的数的整除性质是不确定的，也需要判断
                len--;
            }
            if (len > 0 && b[i] % b[s[len]] != 0)
                return false;//满足单调栈中的整除性质
            s[++len] = i;
        }
        return true;
    };//单调栈check
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        mi = min(mi, a[i]);
        if (i != 1)
            g = __gcd(g, abs(a[i] - a[i - 1]));
    }
    if (g==0)
    {
        cout << k << " " << ((1LL + k) * k >>1) << '\n';
        return;
    }//警醒：对于gcd问题注意特判gcd=0的情况
    for (int i = 1; i * i <= g; i++)
    {
        if (g % i == 0)
        {
            d.push_back(i);
            if (i != g / i)
                d.push_back(g / i);
        }
    }//求因数
    for (auto num : d)
    {
        int add = num - mi;
        if (add > k || add <= 0)
            continue;
        if (check(add))
        {
            cnt++;
            ans += add;
        }
    }
    cout << cnt << " " << ans << '\n';
}

signed main()
{
    // freopen("data.txt", "r", stdin);
    ios::sync_with_stdio(false);
    cin.tie(0);
    int _ = 1;
    cin >> _;
    while (_--)
    {
        solve();
    }
    return 0;
}
```
