# D. 有限小数

## 【题目描述】

给定两个互质正整数 $a, b$，你需要求两个非负整数 $c, d$，满足以下两个条件：

- $\frac{a}{b} + \frac{c}{d}$ 为十进制下的整数或有限小数。
- $1 \leq d \leq 10^9$。

在所有满足条件的非负整数对 $(c, d)$ 中，请求出 $c$ 最小的一对。

一个有理数 $x$ 是十进制下的有限小数，当且仅当将 $x$ 在十进制下以小数形式写出后，小数点后的位数是有限的，即存在正整数 $k$，整数 $p$ 和整数数组 $(q_1, q_2, \ldots, q_k)$ 满足 $0 \leq q_i \leq 9$，使得 $x = p + \sum_{i=1}^k q_i \cdot 10^{-i}$。

## 【输入格式】

从标准输入读入数据。  
第一行包含一个正整数 $T (1 \leq T \leq 10^4)$，表示数据组数。  
每组数据包含一行两个正整数 $a, b (1 \leq a \leq b \leq 10^6)$，含义如题目描述所示。保证 $\gcd(a, b) = 1$。

## 【输出格式】

输出到标准输出。  
对于每组数据，输出一行两个非负整数 $c, d$。如果有多组正确答案，输出任意一组即可。

## 【样例1输入】

4
1 2
2 3
3 7
19 79

## 【样例1输出】

0 1
1 3
1 14
3 316

## 【样例1解释】

对于第一组数据，由于 $\frac{1}{2} = 0.5$ 是有限小数，因此输出 $(c,d)$ 满足 $c = 0$ 且 $1 \leq d \leq 10^9$ 即可。

对于第二组数据，$\frac{2}{3} + \frac{1}{3} = 1$ 是整数，且 $\frac{2}{3} = 0.666\ldots$ 不是有限小数，因此 $c = 1$ 是最小可能值。

对于第三组数据，$\frac{3}{7} + \frac{1}{14} = \frac{1}{2} = 0.5$ 是有限小数。

对于第四组数据，$\frac{19}{79} + \frac{3}{316} = \frac{1}{4} = 0.25$ 是有限小数，且可以证明不存在 $0 \leq c \leq 2$，$1 \leq d \leq 10^9$ 使得 $\frac{19}{79} + \frac{c}{d}$ 是有限小数。



# 思路：

# D. 有限小数

给定两个互质整数 $a, b$，求两个目标非负整数 $c, d$ 使得：

$$\frac{a}{b} + \frac{c}{d}$$

是十进制下的整数或有限小数，且 $1 \leq d \leq 10^9$，最小化 $c$。

设 $w$ 是 $b$ 不含有 2 或 5 的最大因子，则显然 $d = 2^x 5^y w$，否则一定有化不开的，设 $L = 10^9$。

（与$\frac{bd}{gcd(ad+bc,bd)}$必须与10互质有关，通过同余方程化简证明，略）

$O(\log^2 L)$ 枚举 $d$ ，考虑 $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$

由于它是有限小数，因此 $ad + bc$ 一定能被 $w^2$ 整除，也就是得到不定方程 $wk - \frac{b}{w}c = \frac{ad}{w}$，拓展欧几里得 容易解出最小的 $c$，把所有的 $c$ 取最小值即可，时间复杂度 $O(\log^3 L)$。

```c++
#include<bits/stdc++.h> 
#define ll long long
using namespace std;
ll exgcd(ll a,ll b,ll &x,ll &y)
{
	if (b==0) 
	{
		x=1;
		y=0;
		return a;
	}
	ll g=exgcd(b,a%b,y,x);
	y-=a/b*x;
	return g;
} //扩欧
void solve()
{
	ll a,b,lc=1e9,ld=0;
	cin>>a>>b;
	ll w=b;
	while (w%2==0) w/=2;
	while (w%5==0) w/=5;
	for (ll i=1;i*w<=1e9;i*=2)
		for (ll j=i;j*w<=1e9;j*=5)
		{
			ll d=j*w,k=0,c=0;
			ll g=exgcd(w,-b/w,k,c);
			ll o=abs(w/g);
			c=(c*j*a/g%o+o)%o;//线性丢番图方程通解形式中的最小值
			if (c<lc)
			{
				lc=c;
				ld=d;
			}
		}
	cout<<lc<<" "<<ld<<'\n';
}
int main()
{
	ios::sync_with_stdio(0);
	cin.tie(0);
	ll _=0;
	cin>>_;
	while (_--)
	{
		solve();
	}
	return 0;
}
/*
4
1 2
2 3
3 7
19 79
 */
```
